Google Core Web Vitals (CWV)

Dikenal juga sebagai:Core Web VitalsCWVMetrik Kecepatan GoogleSinyal Pengalaman Halaman Google
Jawaban Singkat & Esensi Kunci

Core Web Vitals (CWV) adalah sekumpulan metrik performa web terstandarisasi dari Google yang mengukur pengalaman pengguna di dunia nyata berdasarkan tiga pilar utama: kecepatan pemuatan (LCP), stabilitas visual (CLS), dan responsivitas interaksi (INP).

💡

Mengapa Penting untuk Bisnis:

Lolos evaluasi Core Web Vitals dengan skor hijau menjamin website Anda disukai Google, menduduki peringkat lebih tinggi, dan membuat calon pembeli betah bertransaksi tanpa rasa kesal.

Penjelasan Mendalam & Konsep Kerja

Sejak tahun 2021, Google secara resmi mengintegrasikan Core Web Vitals ke dalam sistem pemeringkat mesin pencari sebagai bagian dari sinyal Page Experience (Pengalaman Halaman). Artinya, website yang lambat, bergoyang-goyang saat dimuat, atau lambat merespons klik pengguna akan kalah bersaing di halaman hasil pencarian Google.

Core Web Vitals diciptakan untuk mengukur apa yang sebenarnya dirasakan oleh manusia saat membuka situs web di kehidupan nyata, bukan sekadar skor laboratorium teoretis. Data ini dikumpulkan Google langsung dari peramban Chrome miliaran pengguna di seluruh dunia melalui Chrome User Experience Report (CrUX).

Tiga pilar resmi Core Web Vitals saat ini meliputi: Largest Contentful Paint (LCP) yang mengukur durasi hingga elemen konten terbesar terlihat di layar; Cumulative Layout Shift (CLS) yang mengukur pergeseran tata letak mendadak yang tidak terduga; serta Interaction to Next Paint (INP) yang mengukur kecepatan browser merespons ketukan atau klik pengguna.

Situs web yang berhasil mencetak skor 'Baik' (Good / Hijau) pada ketiga metrik ini tidak hanya mendapatkan keuntungan prioritas algoritma Google, namun juga mencatat tingkat retensi pengunjung yang jauh lebih tinggi dan penurunan rasio pengabaian keranjang belanja.

Bagi pemilik bisnis, berinvestasi pada teknologi web modern yang lolos Core Web Vitals adalah benteng pertahanan terbaik untuk memastikan setiap rupiah anggaran promosi tidak terbuang percuma akibat website yang lambat dibuka di ponsel pintar.

Langkah Praktis Penerapan untuk Website Bisnis

1

Uji Performa di Google PageSpeed Insights

Masukkan URL website Anda di pagespeed.web.dev untuk melihat status penilaian riil Core Web Vitals data lapangan (CrUX).

2

Optimalkan Gambar dan Font Web

Konversi foto produk ke format WebP generasi terbaru dan gunakan font display: swap untuk mempercepat skor LCP di bawah 2,5 detik.

3

Tetapkan Dimensi Lebar dan Tinggi Elemen Gambar

Selalu cantumkan atribut width dan height eksplisit pada seluruh gambar dan banner untuk mengunci nilai CLS di bawah 0,1.

4

Pangkas Skrip JavaScript Pihak Ketiga yang Berat

Tunda pemuatan widget obrolan atau pelacak yang tidak penting agar browser responsif dan meraih skor INP di bawah 200ms.

Pertanyaan yang Sering Diajukan (FAQ)

Berapa lama waktu yang dibutuhkan Google untuk memperbarui status Core Web Vitals?

Data lapangan CrUX dihitung berdasarkan jendela pergerakan 28 hari terakhir. Perbaikan teknis yang Anda lakukan hari ini akan tercermin secara bertahap dalam kurun 4 minggu ke depan.

Apakah Core Web Vitals lebih penting daripada kualitas konten?

Kualitas dan relevansi konten tetap menjadi faktor nomor satu. Namun jika ada dua website dengan konten yang sama-sama berkualitas, situs dengan Core Web Vitals terbaik akan memenangkan peringkat teratas.

Apa perbedaan antara data Lab dan data Lapangan (Field Data)?

Data Lab disimulasikan dalam kondisi pengujian komputer tunggal tetap. Data Lapangan dikumpulkan dari jutaan pengguna nyata dengan berbagai tipe ponsel dan kondisi jaringan internet sebenarnya.

Bagaimana arsitektur platform kami memastikan Core Web Vitals hijau?

Platform kami menggunakan Next.js App Router dengan Static Site Generation (SSG), CSS Tailwind murni tanpa runtime JS berat, dan gambar lokal teroptimasi yang menghasilkan skor 95-100 di PageSpeed.

Largest Contentful Paint (LCP)

Largest Contentful Paint (LCP) adalah metrik Core Web Vitals yang mengukur waktu yang dibutuhkan peramban untuk merender dan menampilkan blok konten terbesar yang terlihat di layar—biasanya gambar banner utama atau blok teks heading judul.

performance

Cumulative Layout Shift (CLS)

Cumulative Layout Shift (CLS) adalah metrik Core Web Vitals yang mengukur stabilitas visual halaman dengan menghitung total frekuensi dan tingkat keparahan pergeseran tata letak elemen mendadak yang tidak diharapkan pengguna.

performance

Interaction to Next Paint (INP)

Interaction to Next Paint (INP) adalah metrik resmi Core Web Vitals terbaru dari Google yang mengukur tingkat responsivitas sebuah website dengan menilai durasi jeda waktu dari saat pengunjung mengklik, mengetuk, atau menekan tombol hingga peramban selesai memperbarui tampilan visual di layar.

performance

Time to First Byte (TTFB) & Kecepatan Server

Time to First Byte (TTFB) adalah durasi waktu yang dibutuhkan peramban web mulai dari mengirimkan permintaan halaman hingga menerima byte data informasi pertama dari server hosting website Anda.

performance

Google PageSpeed Insights (PSI) & Data CrUX

Google PageSpeed Insights (PSI) adalah alat diagnostik performa resmi dari Google yang menganalisis kecepatan halaman web di perangkat seluler dan desktop, menyajikan perpaduan antara data pengalaman pengguna dunia nyata (CrUX) dan simulasi data laboratorium.
